# Connect4-Online

A real-time two-player Connect 4 website built with Node.js, Express, Socket.IO, HTML, CSS, and JavaScript.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:3000` in two browser tabs or devices. One player creates a room and shares the six-character code; the second player enters it to join.

## Test

```bash
npm test
```
